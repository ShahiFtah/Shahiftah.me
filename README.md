# shahiftah.me

Personlig portefølje med **tre designkonsepter som bytter automatisk hver dag** (norsk tid):

| Konsept | Idé |
|---|---|
| 🚇 T-banelinja | Karrieren som en T-banelinje – utdanning, jobb og gründerskap som stasjoner |
| 📐 Byggetegningen | Siden som et teknisk tegningssett, godkjent med stempel |
| 💻 System-boot | Et operativsystem som starter opp og laster moduler |

**Forhåndsvis:** [tbane](https://shahiftah.me/?design=tbane) · [tegning](https://shahiftah.me/?design=tegning) · [boot](https://shahiftah.me/?design=boot)

**Teknisk**
- Ren HTML/CSS/JS, ingen byggesteg – hostet på GitHub Pages
- Animasjoner med GSAP + ScrollTrigger, myk scroll med Lenis (selv-hostet)
- Designet velges i `index.html` ut fra dato, så alle ser samme design samme dag
- Streng Content-Security-Policy, respekterer `prefers-reduced-motion`
- Hemmelighet: trykk **T** på T-banelinja 😉
